# Human Control Interface (GIST Classifier – Green Project)
# Overview

This project is a computer vision-based Human Control Interface that recognizes and classifies hand gestures in real time. It enables users to interact with and control their computer using predefined hand gestures, allowing execution of custom workflows such as opening applications or triggering system commands.

The system was developed as a team project, where my main contribution was in the machine learning and computer vision classification module.

# Objective

The goal of this system is to build an intuitive gesture-based control interface that allows users to:

Recognize hand gestures from live camera input
Map gestures to system commands or workflows
Enable natural human–computer interaction without traditional input devices

The application enables users to:

Control computer actions using hand gestures
